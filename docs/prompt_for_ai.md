# Промпт для генерации презентации

## Контекст проекта

Ты — дизайнер презентаций. Тебе нужно создать профессиональную презентацию (7-8 слайдов) для защиты дипломного/курсового проекта.

## О проекте

**Название:** Адаптивная платформа обучения с ИИ-репетитором

**Описание:** Full-stack веб-приложение (LMS) для адаптивного обучения с интервальным повторением, ИИ-репетитором на локальной модели и ролевой моделью доступа.

**Стек технологий:**
- Backend: FastAPI (Python), SQLAlchemy 2.0, PostgreSQL, Redis, JWT-аутентификация
- Frontend: React 18, TypeScript, Redux Toolkit, Tailwind CSS
- AI: Ollama (llama3.2:3b) — локальная LLM, RAG-архитектура
- Infra: Docker, Docker Compose

**Ключевые фичи:**
1. Ролевая модель: STUDENT / TEACHER / ADMIN
2. Курсы с иерархией тем (DAG)
3. Карточки для интервального повторения с алгоритмом SM-2
4. ИИ-репетитор с RAG: загружает материалы, отвечает только по ним
5. Система домашних заданий с чатом обратной связи
6. ИИ-подхват: если учитель не отвечает, ИИ проверяет работу
7. Локализация RU/EN + темная тема

**Алгоритмы:**
- SM-2 (SuperMemo-2): ease factor, interval, repetitions, авторасчет quality
- RAG: chunking (400 слов), Ollama embeddings, косинусное сходство, strict mode
- ИИ-подхват: триггер по таймауту или ручной запрос

**Демо-данные:**
- 4 курса (Mathematics, Physics, English, Programming)
- 14 тем, 42 карточки
- 5 заданий, 3 сабмишена с AI/Teacher фидбеком

## Структура презентации (7 слайдов)

### Слайд 1: Титульный
- Название проекта
- ФИО, группа
- Логотип/иконка (🧠 или 📚)

### Слайд 2: Цель, задачи, инструменты
- Цель: комплексная LMS с адаптивным обучением
- 6 задач (роли, курсы, SM-2, ИИ, ДЗ, локализация)
- Стек: FastAPI + React + PostgreSQL + Redis + Docker + Ollama
- Используй иконки для технологий

### Слайд 3: Анализ проблемной области
- 5 проблем традиционного обучения (иконки ❌)
- Таблица сравнения существующих систем (Anki, Quizlet, Coursera, Khan Academy)
- Вывод: на рынке нет комплексного решения

### Слайд 4: Архитектура системы
- Схема: React → FastAPI → PostgreSQL + Redis + Ollama
- 6 модулей с иконками:
  - 🔐 Auth (JWT + роли)
  - 📚 Courses (курсы + темы)
  - 🃏 Flashcards + SM-2
  - 🤖 AI Tutor (RAG)
  - 📝 Homework (задания + чат)
  - 👨‍🏫 Teacher (правила + материалы)

### Слайд 5: Алгоритмы — изюминки системы
- SM-2: формула + график кривой забывания
- RAG Pipeline: 4 шага (chunking → embeddings → search → generation)
- ИИ-Подхват: схема "Студент → ДЗ → Чат → ИИ/Учитель"
- Используй диаграммы и стрелки

### Слайд 6: Как пользоваться системой
- Два столбца: Студент / Учитель
- 4-5 шагов для каждой роли
- Скриншоты или мокапы интерфейса (если можешь)
- Упомяни переключатель языка и темную тему

### Слайд 7: Результаты и выводы
- Чеклист реализованного (7 пунктов с ✅)
- Стек технологий (логотипы)
- GitHub ссылка
- Контакты

## Требования к дизайну

- Современный минималистичный стиль
- Цветовая схема: индиго/фиолетовый акцент + белый/темный фон
- Используй иконки (emoji или Font Awesome)
- Диаграммы и схемы вместо сплошного текста
- Крупный шрифт для заголовков, читаемый для текста
- Контрастные цвета для важных элементов
