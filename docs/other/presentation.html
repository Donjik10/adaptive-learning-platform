Цель, задачи, инструменты

Цель: разработать веб-платформу адаптивного обучения, объединяющую курсовый контент, интервальное повторение, AI-поддержку и взаимодействие студента с преподавателем.

Ключевые задачи

  • роли student / teacher / admin и JWT-аутентификация;
  • структура курс - тема - карточки;
  • модифицированный алгоритм SM-2;
  • локальный ИИ-репетитор на Ollama;
  • задания, отправки и чат по работе;
  • RU/EN и темная тема.

Инструментальные средства

  • Backend: FastAPI, SQLAlchemy 2.0 async, asyncpg, Pydantic v2, JWT
  • Frontend: React 18, TypeScript, Redux Toolkit, Tailwind CSS, Axios
  • Data / Infra: PostgreSQL 15, Redis 7, Docker Compose
  • AI: Ollama llama3.2:3b, OpenAI-compatible API

Анализ проблемной области

Проблемы обучения

  • нет персонализации темпа и сложности;
  • материал быстро забывается без повторения;
  • обратная связь по заданиям приходит с задержкой;
  • ИИ общего назначения не знает материалы курса;
  • контент, карточки, чат и видео часто разделены по разным сервисам.

Алгоритмы и изюминки системы

1. Modified SM-2

  • качество ответа рассчитывается автоматически;
  • учитываются корректность, время, уверенность и серия;
  • после этого применяется стандартная формула SM-2.
base = 4.0 if correct else 1.0
quality = base + time_bonus
                + confidence_adj
                + streak_bonus
quality = floor(clamp(0..5))

2. Пересчет из истории

Состояние повторений можно пересчитать повторным воспроизведением записей review_history.

3. RAG Tutor

  • chunking: 400 слов / overlap 50;
  • эмбеддинги через /v1/embeddings;
  • хранение в PostgreSQL как JSON-текст;
  • поиск по косинусному сходству;
  • ответ с учетом teacher prompt и strict mode.

4. Personalized Explain

Отдельный endpoint /ai-tutor/explain строит объяснение ошибки с учетом learning_style студента.

Как пользоваться системой

Студент

  • вход: demo@student.com / demo123;
  • выбор курса и темы на Dashboard;
  • повторение карточек в Review;
  • отправка решения по заданию;
  • чат с преподавателем внутри submission;
  • ручной запрос AI Review;
  • вопросы AI-репетитору по материалам курса.

Преподаватель

  • вход: demo@teacher.com / teacher123;
  • настройка teacher rules;
  • загрузка текстовых материалов для RAG;
  • просмотр и проверка отправок;
  • ответы студенту в чате;
  • добавление видеоматериалов по курсу.

Результаты и выводы
