## Слайд 2. Цель, задачи, инструментальные средства

**Цель работы**

Разработать веб-платформу адаптивного обучения, объединяющую учебный контент, интервальное повторение, AI-поддержку и взаимодействие студента с преподавателем в рамках одной LMS.

**Основные задачи**

- реализовать ролевую модель `student / teacher / admin`;
- создать структуру `курс -> тема -> карточки`;
- внедрить модифицированный алгоритм SM-2;
- реализовать ИИ-репетитора на локальной модели Ollama;
- добавить систему домашних заданий, отправок и чата;
- реализовать прикрепление файлов к отправкам и загрузку файлов в RAG;
- обеспечить поддержку RU/EN и светлой/темной темы;
- реализовать ролевую навигацию с визуальным разделением меню.

**Инструментальные средства**

- Backend: `FastAPI`, `SQLAlchemy 2.0 async`, `asyncpg`, `Pydantic v2`, `JWT`
- Frontend: `React 18`, `TypeScript`, `Redux Toolkit`, `Tailwind CSS`, `Axios`
- Data/Infra: `PostgreSQL 15`, `Redis 7`, `Docker Compose`
- AI: `Ollama llama3.2:3b`, OpenAI-compatible API

## Слайд 3. Анализ проблемной области

**Проблемы традиционного и массового онлайн-обучения**

- отсутствие персонализации: один темп и одна сложность для всех;
- быстрое забывание материала без регулярного повторения;
- задержка обратной связи по домашним заданиям;
- разрыв между учебным контентом и ответами ИИ общего назначения;
- фрагментация инструментов: курсы, карточки, чат и видео находятся в разных сервисах.

**Анализ существующих систем**

| Система | Что умеет | Чего не хватает |
| --- | --- | --- |
| Anki | сильное интервальное повторение | нет LMS-структуры и ИИ |
| Quizlet | простые карточки и готовые наборы | слабая адаптивность |
| Moodle / Classroom | курсы и задания | нет SM-2 и teacher-driven RAG |
| Coursera / Khan Academy | качественный контент и видео | нет персонального цикла повторений |
| ChatGPT | хорошие объяснения | нет курса, истории и правил преподавателя |

**Вывод**

Наиболее востребованным является гибридное решение, которое сочетает LMS, интервальное повторение и управляемый учебный ИИ.

## Слайд 4. Архитектура системы и модули

```text
React Frontend
Dashboard | Review | Homework | Tutor | Videos
        |
        v
FastAPI Backend
Auth | Subjects | Topics | Flashcards | Reviews
Homework | Teacher | Tutor | AI-Tutor | Videos
        |
        +--> PostgreSQL 15
        +--> Ollama (LLM + embeddings)
        +--> Redis 7
```

**Функциональные модули**

- `Auth` — регистрация, вход, JWT, роли;
- `Content` — предметы, темы, карточки;
- `Review` — история повторений и SM-2-состояние;
- `RAG Tutor` — материалы курса, teacher rules, strict mode;
- `Homework` — задания, отправки, чат, AI-review;
- `Videos` — видеоматериалы курса;
- `UI services` — локализация, тема, маршрутизация и защита интерфейса.

## Слайд 5. Алгоритмы и изюминки системы

**1. Модифицированный SM-2**

- качество ответа вычисляется автоматически;
- учитываются:
  - правильность ответа;
  - время ответа;
  - уверенность;
  - серия повторений;
- далее применяется классическая формула SM-2 для `ease_factor`, `interval`, `repetitions`.

**2. RAG по материалам преподавателя**

1. загрузка текста;
2. разбиение на фрагменты `400 слов / overlap 50`;
3. эмбеддинги через `Ollama /v1/embeddings`;
4. поиск по косинусному сходству;
5. генерация ответа с учетом teacher prompt и strict mode.

**3. Персонализированные объяснения**

- отдельный endpoint `/ai-tutor/explain`;
- стиль ответа зависит от `learning_style`;
- ИИ объясняет не абстрактно, а с учетом ошибки студента и карточки.

**4. Извлечение текста из файлов (PDF, DOCX, TXT)**

- преподаватель загружает файл, текст извлекается автоматически;
- поддержка PyPDF2 для PDF и python-docx для DOCX;
- извлеченный текст проходит стандартный RAG-пайплайн.

**5. Загрузка файлов при отправке задания**

- студент прикрепляет файлы (до 10 МБ) при сдаче работы;
- преподаватель видит индикатор 📎 и может скачать файл.

## Слайд 6. Как пользоваться системой

**Студент**

1. Войти в систему: `demo@student.com / demo123`
2. Выбрать курс и тему на Dashboard
3. Открыть `Review` и повторять карточки
4. Перейти в раздел заданий, отправить решение
5. Общаться в чате с преподавателем или запросить `AI Review`
6. Задать вопрос AI-репетитору по материалам курса

**Преподаватель**

1. Войти: `demo@teacher.com / teacher123`
2. Настроить поведение ИИ в разделе teacher rules
3. Загрузить текстовые материалы для RAG
4. Проверять отправки студентов и отвечать в чате
5. Добавлять видеоматериалы по курсу

## Слайд 7. Результаты и выводы

**Что реализовано**

- ролевая модель доступа и JWT-аутентификация;
- 4 курса, 14 тем, 42 карточки в демо-наборе;
- modified SM-2 с автоподсчетом качества;
- teacher-driven RAG на локальной модели `llama3.2:3b` с загрузкой файлов (PDF, DOCX, TXT);
- домашние задания с прикреплением файлов и созданием заданий через UI преподавателя;
- статусы `pending`, `ai_reviewed`, `reviewed`;
- ролевая навигация с визуальным разделением меню (синий — студент, зеленый — преподаватель);
- RU/EN и светлая/темная тема;
- 5 демонстрационных видеоматериалов.

**Вывод**

Проект демонстрирует реальную интеграцию LMS и AI-компонентов в одном приложении и может быть расширен в сторону более глубокой аналитики, автоматизации teacher workflows и масштабируемого векторного поиска.
