🧠 Алгоритмы — изюминки системы

SM-2 (SuperMemo-2)

quality = correctness × time × confidence × streak

if quality ≥ 3:
  interval = interval × ease_factor
else:
  interval = 1

ease_factor += 0.1 - (5-q)×(0.08+(5-q)×0.02)

Автоподстройка интервалов под каждого студента

RAG Pipeline

  1. 📄 Chunking: 400 слов, overlap 50
  2. 🔢 Embeddings: Ollama /v1/embeddings
  3. 🔍 Search: косинусное сходство
  4. 💬 Generation: LLM + контекст

ИИ-Подхват

Студент → Отправка ДЗ → Чат →
→ Учитель отвечает? ✅
→ Нет? → ИИ проверяет автоматически ⚡

👤 Как пользоваться системой

🎓 Студент

  1. Вход (demo@student.com)
  2. Dashboard → выбор курса
  3. Review: Space — перевернуть, 1/2 — ответ
  4. My Assignments → отправка решений
  5. Чат: обсуждение или ⚡ ИИ-проверка

👨‍🏫 Учитель

  1. Вход (demo@teacher.com)
  2. Submissions — проверка работ
  3. AI Rules — загрузка материалов
  4. Настройка промпта для ИИ
  5. Чат — обратная связь студентам
