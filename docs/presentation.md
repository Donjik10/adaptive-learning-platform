## Слайд 2: Цель, задачи, инструменты

**Цель:**
Разработать LMS-платформу с адаптивным обучением, интервальным повторением и ИИ-репетитором

**Задачи:**
- Ролевая модель (студент/учитель/админ)
- Курсы с темами и карточками
- Алгоритм SM-2 для планирования повторений

Backend: FastAPI, SQLAlchemy, PostgreSQL, Redis, Ollama
Frontend: React, TypeScript, Redux Toolkit, Tailwind CSS
Infra: Docker, Docker Compose

## Слайд 3: Анализ проблемной области

**Проблемы традиционного обучения:**

❌ Нет персонализации — один темп для всех
❌ Эффект забывания — 80% материала теряется за неделю
❌ Нет интервального повторения — хаотичные повторения
❌ Задержка обратной связи — дни на проверку
❌ Не учитываются стили обучения

**Анализ существующих систем:**

| Система | Чего не хватает |
|---------|----------------|
| Anki | Нет курсов, нет ИИ |
| Quizlet | Нет адаптивного алгоритма |
| Coursera | Пассивное видео, нет повторений |
| Khan Academy | Нет ИИ-репетитора с RAG |

**Вывод:** Нет комплексного решения с курсами + SM-2 + ИИ + ролями

## Слайд 5: Алгоритмы — изюминки системы

**SM-2 (SuperMemo-2)**
```
quality = correctness × time × confidence × streak

if quality ≥ 3:
    interval = interval × ease_factor
else:
    interval = 1  # сброс
```
Автоподстройка интервалов под каждого студента

**RAG Pipeline**
1. Загрузка материала → chunking (400 слов)
2. Эмбеддинги через Ollama → хранение в PostgreSQL
3. Запрос → поиск по косинусному сходству
4. Контекст + промпт учителя → ответ LLM

**ИИ-Подхват**
- Учитель не отвечает? → ИИ автоматически проверяет
- Или студент нажимает "⚡ Спросить ИИ"
- ИИ анализирует работу + правила учителя

## Слайд 6: Как пользоваться системой

**Студент:**
1. Вход (demo@student.com / demo123)
2. Dashboard → выбор курса → Review
3. Space — перевернуть, 1/2 — ответ
4. My Assignments → отправка решений
5. Чат: обсуждение или ⚡ ИИ-проверка

**Учитель:**
1. Вход (demo@teacher.com / teacher123)
2. Submissions — проверка работ
3. AI Rules — загрузка материалов и настройка ИИ
4. Чат — обратная связь студентам

**Особенности:**
- 🌐 RU/EN переключатель
- 🌙 Темная тема
- 🤖 Локальный ИИ (без API-ключей)
- 📊 Статистика прогресса
